1 · Structuring the drive

One drive folder can hold many projects and initiatives. Shared areas sit at the top; each project gets its own folder with identical subfolders.

Rules

  • Top-level folders are numbered (0 to 4) and never re-ordered.
  • Each project or initiative is a folder inside 2_Projects.
  • Every project uses the same subfolders, so anyone can find things in any project.
  • Partner-shared files live only in the partner shared folder.
  • Keep it to 4 levels deep.
