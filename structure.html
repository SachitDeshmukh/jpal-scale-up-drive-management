Structuring the drive

Two kinds of drive folders: one root folder for shared resources and initiatives, and one seperate drive per project.

Rules

  • New project: create its own drive folder, using the project folder structure.
  • New initiative: add a subfolder inside 2_Initiatives in the root folder.
  • Numbered folders are never re-ordered.
  • Partner-shared files live only in the partner folder of a project.
  • Keep it to 4 levels deep.

1. Root folder

Shared resources and initiatives. No project folders live here. Click a folder to open it.

2. Project drive

One of these per project, each in its own drive folder. Click a folder to open it.
