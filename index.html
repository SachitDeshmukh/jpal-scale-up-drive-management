Drive management, file names and archiving

A short guide to keeping our shared drive easy to navigate, whichever team or project you work on. Read and experiment with the rules.

Three things to get right

Structure

One drive, one folder per project, the same subfolders in each.

 Naming

Project, purpose, date. Pick an order and get a name.

 Archiving

Where old files go, and how to log it.

Golden rules

  1. Top-level folders are numbered and never re-ordered.
  2. One folder per project or initiative, same subfolders in each.
  3. Name files Project_Purpose_Date.
  4. Never call a file “final”. The date shows which is latest.
  5. Archive by project, then milestone, and log it in 0_README.
